# investment-agent

Простой Python-проект для MVP инвестиционного аналитика.

Теперь проект получает:

- реальные данные по российским акциям через официальный MOEX ISS API;
- новостной фон по компаниям через бесплатную RSS-ленту Google News.

## Структура проекта

```text
investment-agent/
├─ main.py
├─ agent.py
├─ requirements.txt
├─ README.md
├─ .env.example
└─ tools/
   ├─ __init__.py
   ├─ market_data.py
   ├─ news.py
   └─ portfolio.py
```

## Как запустить проект

1. Убедитесь, что у вас установлен Python 3.10 или новее.
2. Откройте терминал в папке проекта:

```powershell
cd C:\Users\Vladimir\Desktop\investment-agent
```

3. Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

4. Активируйте виртуальное окружение:

```powershell
.venv\Scripts\Activate.ps1
```

5. Установите зависимости:

```powershell
pip install -r requirements.txt
```

6. Запустите приложение:

```powershell
python main.py
```

7. Введите тикер, например:

```text
SBER
```

## Как это работает

- `main.py` принимает тикер из CLI и выводит готовый текст анализа.
- `agent.py` собирает ответ для пользователя на русском языке.
- `tools/market_data.py` делает запросы в официальный MOEX ISS API.
- `tools/news.py` получает новости через бесплатный RSS-поиск Google News.
- Для одного тикера модуль рыночных данных запрашивает:
  - котировку и карточку бумаги с рынка `stock / shares`;
  - расширенное описание бумаги и основную торговую доску.
- Для новостей проект:
  - берет тикер и название компании;
  - собирает бесплатный RSS-запрос в Google News;
  - старается отфильтровать бытовые и слабые по смыслу публикации;
  - классифицирует заголовки как `инвестиционно значимая`, `нейтральная` или `слабо релевантная`;
  - показывает сначала более полезные для инвестора новости;
  - честно пишет, если новости не пришли или не нашлись.
- Затем проект показывает:
  - реальную цену акции, если MOEX ее вернул;
  - название бумаги;
  - описание типа бумаги;
  - режим торгов;
  - блок `Новостной фон`;
  - честное сообщение, если сектор, цена или новости не пришли.

## Какие тикеры можно вводить

Сейчас поддерживаются только акции рынка MOEX shares.

Примеры тикеров:

- `SBER`
- `GAZP`
- `LKOH`
- `ROSN`
- `VTBR`

Если ввести тикер, который не относится к акциям MOEX, проект честно скажет, что бумага не найдена на поддерживаемом рынке.

## Что теперь берется из MOEX

Из MOEX ISS API теперь берутся реальные данные:

- цена акции;
- источник цены внутри ответа MOEX, например `LAST` или `LCURRENTPRICE`;
- краткое и полное название бумаги;
- описание типа бумаги;
- уровень листинга, если он есть;
- основная торговая доска;
- ISIN;
- предыдущая доступная цена закрытия, если она есть.

Важно:

- сектор MOEX ISS API может не вернуть;
- если сектор не пришел, проект не придумывает его и пишет об этом прямо;
- если MOEX недоступен или вернул пустой ответ, проект тоже пишет об этом прямо.

## Что теперь берется из новостей

Для новостного блока теперь используется бесплатный источник без API-ключа:

- Google News RSS search feed.

Из него проект берет:

- заголовки публикаций;
- дату публикации;
- название источника;
- простую классификацию релевантности заголовков:
  - `инвестиционно значимая`;
  - `нейтральная`;
  - `слабо релевантная`;
- короткую эвристическую оценку фона по более релевантным заголовкам: позитивный, негативный, смешанный или нейтральный.

Важно:

- если новостей нет, проект не придумывает их;
- если новостная лента недоступна, проект честно пишет об этом;
- если все найденные новости выглядят слабо релевантными, проект пишет об этом прямо;
- фильтрация и классификация работают по ключевым словам в заголовках, а не по полному тексту статьи;
- модуль старается отсеивать бытовые публикации и оставлять новости про отчетность, дивиденды, прибыль, ставки, санкции, стратегию, рейтинги, рекомендации аналитиков, корпоративные события и биржевую торговлю;
- это не полноценный sentiment analysis, а только простая оценка по словам в заголовках;
- Google News RSS лучше рассматривать как удобный бесплатный источник для локального или личного использования; перед публичным или коммерческим использованием стоит отдельно проверить условия Google.

## Какие данные пока не подключены

- анализ текста самих новостей и статей пока не подключен;
- анализ портфеля все еще работает как локальная заглушка;
- веб-интерфейса нет;
- автопокупки акций нет.

## В какие файлы смотреть

- `tools/market_data.py` - вся логика работы с MOEX ISS API.
- `agent.py` - сборка итогового ответа для пользователя.
- `tools/news.py` - логика новостей через бесплатный RSS-источник.
- `tools/portfolio.py` - пока заглушка для контекста портфеля.
- `.env.example` - пример настроек для провайдера данных и таймаута.

## Ограничения

- поддерживаются только акции MOEX;
- проект не поддерживает облигации, фьючерсы и другие рынки;
- интернет-соединение обязательно;
- если MOEX временно недоступен, анализ по бумаге не строится и выводится понятное сообщение;
- если новостный RSS-источник временно недоступен, блок новостей покажет честное сообщение вместо выдуманных новостей;
- фильтрация новостей эвристическая, поэтому часть полезных заголовков может попасть в `нейтральные`, а часть спорных публикаций все еще может пройти в выборку;
- проект не является инвестиционной рекомендацией.
